# Cork

Native macOS utility. Swift 6, macOS 14+, SwiftPM; no third-party runtime dependencies.

- Build: `./scripts/build.sh` → `build/Cork.app`, including `Contents/MacOS/cork-mcp`.
- Focused checks: `./scripts/check.sh` (dependency-free `CorkChecks` executable; this host's Command Line Tools lacks Swift Testing).
- Do not change global Xcode selection or accept Xcode agreements. `CORK_SDK` selects a task-scoped SDK; default is the installed Command Line Tools macOS 26.5 SDK.
- Quit the Cork copy whose signed bundle will be rebuilt or installed. Overwriting a running signed executable can cause macOS to terminate it; building a separate bundle does not overwrite the installed copy.
- Use explicit `CORK_DATA_DIR` and `CORK_SOCKET` for both app and bridge when testing. Do not overwrite a user's real board with sample artwork.
- The running app owns all board writes. MCP goes through the protected Unix socket; preserve atomic batch edits, increasing revisions and undo. Never retry a mutation after an ambiguous response failure.
- Blocking socket callbacks must be created outside MainActor; accepted Darwin sockets must explicitly clear inherited `O_NONBLOCK`. Both contracts have runtime checks.
- UI/persistence boundaries and rendering live in `docs/DEVELOPMENT.md`; source provenance and limits are in `docs/RESEARCH.md`. No copied Übersicht or PinMark source/assets.
- In the library's `HSplitView`, keep both children explicitly sized to available height, including the no-selection state. An intrinsic-height placeholder previously collapsed the item list into the center.
- Screenshots require macOS Screen Recording permission for Cork. Report permission denial truthfully; do not modify TCC databases or bypass the system authentication flow.
- Match Tuck/Snap's README and native monochrome icon family. The print/note content is intentionally physical; app controls remain standard native controls.
- `collection.json` is a real user's curated photo pool, separate from `board.json`. Preserve its metadata and local media; do not replace either with test fixtures. Collection imports and dice rolls go through the running app, and a roll must preserve notes, other displays, undo and blank captions.
- `wallpapers.json` is also user data owned by the running app. Wallpaper imports measure actual pixels and colours; automatic selection must satisfy native-resolution and crop-retention limits. Never upscale thumbnails to make them eligible.
- Fill Empty preserves every existing item's geometry; kept images survive rolls and automatic arrangement too. Palette, wallpaper and photo changes commit and undo as one scene. Both Carbon shortcuts share one application event handler and retain their old registrations until a proposed settings save succeeds.
- A note's `includeInLayout` defaults to true for legacy data. Overlay notes (`false`) never consume packing space or move during arrangement, and render after every photo via `Board.itemsBackToFront`, regardless of newer photo z-indices. Preserve both note kinds through rolls and Fill Empty.
- Custom wallpaper must also synchronize the native desktop image so macOS can tint its menu bar. Save original URL/options before native writes, restore on System/quit, preserve external changes and pending recovery entries, and use video posters. A desktop cover window alone cannot fix the menu bar. Keep same-key refreshes from cancelling an in-flight System wallpaper load.
- Paired palettes declare two `majorColours`; balance visible print area around retained anchors without weakening source diversity or geometry preservation. Never average opposing photo hues for wallpaper matching: a coloured backdrop must match a represented family. Existing single-family scenes retain their stricter blue/pink mismatch guard. Personal mood memberships remain catalogue data, not bundled media.
- Custom `colourPair` choices search the whole classified collection; presets retain curated memberships. `colourProfile` stores measured pixel coverage (strong ≥18%, accents ≥4%), never inferred cluster weights. The repository owns atomic cache backfill/imports; controller jobs are cancelled and generation-fenced. Preserve existing source metadata, memberships, media and saved scenes during classification. A preset selection clears the custom pair; never save both at once.
- Cork Importer reads browser cookies only after its explicit disclosure/consent. Query Pinterest rows read-only; use ephemeral scoped HTTPS sessions, never write browser keys/cookies to reviews, manifests, logs or the Cork socket. Profile-folder access uses the native file picker; never suggest Full Disk Access as a shortcut. Ambiguous batch replies require ID/source reconciliation before another mutation.
- Library capacity is 20,000 image/video prints. Keep layout candidates bounded and balanced by source identity, aspect and both requested colour families. `sourceBoardID` is stable grouping; `sourceBoard` remains readable, with legacy labels preserved. Favourites reference existing media, restore scene/mood, and preserve global schedule/shortcuts/visibility. Scheduling is opt-in, coalesces missed runs, and must not cancel the roll that saves its next deadline.

- Video prints use an owned PNG `assetFile` at rest plus `video.file` and five measured frame profiles. Use `isVisualPrint` for layout/visibility/favourites; cover colours balance resting area while every sampled frame gates palette eligibility. Playback stays muted, lazy and released on exit/edit/hide/sleep/removal. Collection `kind` defaults to image; explicit `removeIDs` excludes catalogue entries without deleting media or changing saved scenes.
- Double-click video wallpaper presentation is transient UI state owned by `DesktopEnvironment`; it reuses Images assets and never edits the saved wallpaper, geometry or undo. Keep it below application windows, restore native poster/player state on return, and defer scheduled rolls while open. Native verification must keep windows hidden and inject wallpaper access so tests cannot interrupt the user's active apps or wallpaper.
- Wallpaper clicks must establish nonactivating keyboard focus, including through hidden-widget covers. Route window key equivalents through Cork's real menu targets/validation; do not register bare Command-R globally. Preserve focus during wallpaper replacement only while the old panel still owns it, so another app's focus wins.
